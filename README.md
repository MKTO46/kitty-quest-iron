# KITTY QUEST: IRON

GitHub Pages edition. Open the published website and select a day to start its assigned workout.

Workouts are saved in this browser using IndexedDB. They are not uploaded to GitHub or synced between devices. Clearing site data removes this copy; use HOME → Export complete training backup regularly. Import a backup through HOME → Merge a training backup to transfer existing history.

To publish: upload this folder's contents to the root of the kitty-quest-iron repository. In Settings → Pages, select Deploy from a branch, main, /(root).

This release includes seven editable routines, set-by-set saving and resume, rep and resistance buttons, and weight suggestions from matching equipment history.
